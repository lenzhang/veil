# Nested checkout snapshots

As of the 2026-11-10 freeze. Each `*.state.txt` records HEAD, branch and status of a nested checkout that is **not** vendored here. Accompanying `*.diff` files are uncommitted deltas at freeze time, with private inventory removed.

`UniXNU-droidvm-extra` is a renamed snapshot of an additional nested checkout; the original local name is not used in this public archive.
